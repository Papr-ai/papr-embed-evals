# schema-1 through the API, code schemas, partial

These are **schema-1** runs (called `papr-embed-v1` at the time, now `papr-embed-schema-1`),
scored through the Papr embeddings API with a `code_search:*` schema per task. They cover
3 of the 10 CoIR tasks, so there is no CoIR mean.

They are **not** the open-weights code-1 models. code-1 results are in `../code1/`.
